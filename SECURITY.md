# Security policy

Report SDK vulnerabilities privately using **Security → Report a vulnerability** in the [Python SDK repository](https://github.com/try-pulse/pulse-agent-sdk-python/security). Include the package version, a minimal reproduction using synthetic data, and the impact.

If private reporting is unavailable, contact a Pulse maintainer privately for a secure channel. Keep credentials, signing secrets, personal data, and vulnerability details out of public issues and pull requests.
